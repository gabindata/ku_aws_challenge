# 말꼬리

**말투를 돌려받는 음성 대화 연습 게임**

말이 막히는 청년을 대상으로 만든 데모입니다. 플레이어는 키보드가 아니라 마이크로
NPC와 이야기하고, 대화가 끝나면 **실제로 한 말을 근거로 자기 말투 리포트**를 받습니다.
잘했는지 채점하는 게 아니라, 자기 말버릇을 처음 알아차리게 하는 것이 목표입니다.

**▶ [지금 해보기](https://malkori.pages.dev)** — 크롬에서 열어 주세요. 마이크 권한이 필요합니다.

> 2026 고려대학교 AI Innovators Challenge 출품작

## 왜 만들었나

알바 스케줄을 조정하고, 사무실에 문의하고, 집주인과 이야기하는 일.
피하기도 어렵고 먼저 꺼내기도 어려운 대화가 있습니다.
고립·은둔 청년처럼 일상의 말 한마디부터 막히는 사람에게는 더 그렇습니다.

연습할 곳이 없다는 게 문제입니다. 실제 상대에게는 한 번뿐이고, 되감을 수 없고,
끝나고 나면 내가 뭘 어떻게 말했는지조차 남지 않습니다.

말꼬리는 그 한 번을 **되감을 수 있게** 만듭니다.
상대는 NPC라 몇 번이든 다시 할 수 있고, 대화가 끝나면 내가 한 말이 그대로 남습니다.

## 어떻게 하나

**1. 말을 겁니다**

마이크 버튼을 누르고 말합니다. 타이핑하지 않습니다.
상대는 LLM이 연기하며, 무엇을 어떻게 말했는지에 따라 반응이 달라집니다.
얼버무리면 되묻고, 약속을 뒤집으면 알아챕니다.

**2. 합의를 만듭니다**

상황마다 상대가 확답을 원하는 지점이 있습니다.
그 지점들이 다 채워지면 대화가 마무리됩니다. 제한 시간은 10분입니다.

**3. 말투 리포트를 받습니다**

성공했든 실패했든 **같은 형식, 같은 비중으로** 나옵니다.

- **한 줄 관찰** — "이번 대화의 말투: 돌려 말하는 설명가"
- **근거 발화** — 그렇게 본 이유가 된, 내가 실제로 한 말
- **말투 축** — 발화 격식 · 직접성 · 쿠션 표현 · 발화 길이
- **총평** — 대화 전체에 대한 한 문단

말투는 성공·실패 판정에 **넣지 않습니다.** 평가가 아니라 거울이기 때문입니다.

## 등장하는 상황

| | 상대 | 장소 | 이야기 |
|---|---|---|---|
| **튜토리얼** | 고금자 | 내 원룸 현관 | 월세가 밀렸고 연락을 피해 왔다. 여기선 실수해도 되돌려 준다 |
| **1** | 양점장 | 동네 편의점 | 야간 알바가 갑자기 그만뒀다. 평일 밤을 맡아 줄 사람을 찾는다 |
| **2** | 한조교 | 정보대학 행정실 | 복학 서류를 기한 뒤에 들고 왔다. 조교에게는 승인 권한이 없다 |
| **3** | 고금자 | 내 원룸 현관 | 방 상태를 봤다. 이대로면 원상복구비가 보증금을 넘는다 |

상대는 각자 사정이 있고, 숨기는 것과 먼저 말하지 않는 것이 따로 있습니다.
플레이어가 묻지 않으면 끝까지 안 나오는 정보도 있습니다.

## 만든 방식

```
음성 → 텍스트 → LLM 판정 → NPC 대사 → 음성
                    ↓
             대화 종료 → 말투 리포트
```

- **음성 인식** Web Speech API (크롬)
- **음성 합성** 일레븐랩스. NPC마다 목소리가 다릅니다
- **대화 판정** AWS Bedrock (대회 게이트웨이). 매 턴 호출
- **화면** Phaser 3 + TypeScript
- **서버** Express + TypeScript

판정을 나눠 맡긴 것이 핵심입니다.
**합의가 성립했는지, 번복됐는지 같은 의미 판단은 LLM이** 합니다.
서버는 의미를 다시 계산하지 않고, 근거와 형식만 검증한 뒤 **필수 합의가 다 찼는지로
성공만** 정합니다. 그래서 상황을 하나 늘릴 때 JSON 파일 하나만 추가하면 되고,
엔진 코드는 건드리지 않습니다.

## 실행

```bash
git clone https://github.com/gabindata/ku_aws_challenge.git
cd ku_aws_challenge

cd server && npm install && cp .env.example .env && npm run dev
cd client && npm install && npm run dev            # http://localhost:5173
```

`.env`를 비워 둬도 전체가 돕니다. `LLM_MODE=stub`이면 가짜 LLM이 답하므로
API 키 없이 화면과 흐름을 볼 수 있습니다. 실제 모델을 부르려면 `.env`의
`LLM_API_KEY`를 채우고 `LLM_MODE=live`로 바꿉니다. 각 값의 설명은 `.env.example`에
있습니다.

음성 인식이 Web Speech API라 **크롬**에서 실행해야 합니다.
